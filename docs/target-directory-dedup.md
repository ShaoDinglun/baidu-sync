# 普通文件转存的目标核对

普通文件转存仅枚举本轮经过日期范围及正则筛选后的目标目录，每个目录在准备阶段枚举一次。文件是否存在按完整目标路径判断，沪深、京市目录中的同名 ZIP 不互相替代。

仅明确的目录不存在允许视为空目录。接口异常、无效 JSON 及递归扫描失败向上传递，任务失败，不再用空列表继续转存。转存提交前重新枚举目标目录；在“不覆盖”策略下发现准备之后出现的同名目标时停止本批，要求重新同步，避免重复提交。既有显式覆盖策略不变。

本修复不自动删除或覆盖已有文件，不把转存错误码 4 一律当成成功，也不修改任务状态掩盖失败。目录枚举与转存并非百度端原子操作，最后核对之后仍可能发生并发冲突，接口错误继续正常上报。

复现背景：2026-11-17，A 股分笔任务扫描沪深历史目录时接口异常，被误判为已有文件 0 个；京市 2026-11 的 11 个 ZIP 实际已存在且与源文件大小、MD5 一致，随后重复转存返回错误码 4。

验证命令：`python -m unittest discover -s tests -p '*.py'`。回归覆盖扫描失败、确认缺目录、跨市场同名、11 个已存在文件重复运行、提交前目标变化、正常新增和嵌套目录重命名。全部通过后再提交；仓库推送与运行服务重启分开核验。
